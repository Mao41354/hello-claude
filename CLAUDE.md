# hello-claude

A personal practice site, deployed live via GitHub Pages.

## How I like to work
- Test changes locally by opening index.html before committing.
- I'll commit and push myself -- walk me through it, don't do it for me.
- When something breaks, I'll describe what I observed. Investigate from
  that; don't ask me to guess the cause.
- After a fix, show me how to verify it before we consider it done.

## Conventions already in use
- JavaScript uses `var`, not `let`/`const`.
- Inline styles on elements, no separate CSS file yet.

## Deploy
- Live at https://mao41354.github.io/hello-claude/
- Pushing to `main` publishes automatically -- no extra deploy step.
